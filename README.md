# VibeOS

> The operating system for the AI-native era — describe what you want, and let AI build it.

## 🚀 Overview

VibeOS is an ongoing project exploring what an operating system could look like in a future where AI can understand human intent, write software, and build complete applications on demand.

Today, using software usually means finding the right application, installing it, configuring it, and learning how to use it.

VibeOS imagines a different future.

Instead of searching for an application, you simply describe what you need.

Want a personal expense tracker? Type it.

Need a dashboard for your business? Type it.

Want a custom productivity tool built specifically for your workflow? Type it.

VibeOS aims to let AI understand your request, generate the required application in the background, configure everything automatically, and make it ready to use within seconds.
